# Recompiler decisions

- 2026-10-03: MAME `taito_f3.cpp` lines 4166–4171 defines World `landmakr` as four 0x80000-byte lanes e61-19.20, e61-18.19, e61-17.18, e61-16.17, interleaved at byte offsets 0,1,2,3. Supplied `roms/landmakr` instead contains e61-13.20, e61-12.19, e61-11.18, e61-10.17: MAME `landmakrj`. Keep distinct validated game configurations; never silently identify Japan as World. Runtime peer and orchestrator notified.
- Orchestrator subsequently approved Japan `landmakrj` (2.01J) as the actual execution target. World remains configuration-only and untested; no additional ROMs will arrive. This resolves the ROM-scope discrepancy rather than blocking the Japanese milestone.
- N64Recomp design reference: https://github.com/N64Recomp/N64Recomp — literal instruction lowering, metadata-guided discovery, per-game TOML, runtime-resolved indirect transfers. N64ModernRuntime reference: https://github.com/N64Recomp/N64ModernRuntime — separate hardware implementation and recompilation bridge. F3 flat ROM needs no relocatable overlays unless RAM execution is observed; unresolved/RAM PCs go through explicit runtime fallback, not invented relocation metadata.
- Dispatch uses emulated PC and stack, never native recursive calls. Basic-block boundary callback permits IRQ delivery without retaining stale PC/flags. Lazy flags must materialize before exceptions or external state observation.
- Source and verification tools are committed. ROM bytes, generated game C, third-party downloaded reference builds, and generated traces remain ignored.
- ABI v1 is now agreed byte-for-byte with the runtime peer: `include/f3rt/cpu_abi.h`, including active/inactive stacks, 020 control registers, opaque runtime pointer, lazy flag fields, cumulative scheduling cycles, runtime-owned sorted dispatch lookup, and one-instruction fallback. Only memory callbacks accept pending flags; other callbacks require canonical SR.
- Python Capstone 5.0.9 is installed into ignored `build/python` for this workstation (`PYTHONPATH=build/python`). The workstation's Python 3.13 `venv`/uv inspection failed due to empty `platform.mac_ver()`; `/usr/bin/python3 -m pip install --target build/python capstone==5.0.9` succeeded. This is an environment workaround, not a package runtime dependency.
- Initial compiler smoke: strict Japan lane load succeeds; World config fails explicitly on missing `e61-19.20`. Discovery: 21,373 instructions, 79,734 unique bytes / 2 MiB (3.802%), 563 candidate functions, 55 unresolved transfers, 18 vector/config seeds and 58 heuristic seeds. This does not certify unknown bytes as data.
- C emission smoke: 21,284 native instruction entries and 89 explicit fallback entries, 6,707 bounded native blocks. All 54 generated translation units compile into `build/native/libf3_recompiled.a` with Clang `-O3 -Wall -Wextra -Werror`; generated output remains ignored.
- Differential validation observed 4,996 passed / 0 failed, with four bitfield instructions reported unsupported (not passes), from 5,000 deterministic cases. Includes multi-instruction lazy flag transitions; native cases run with UBSan and warnings as errors. Earlier failing regressions caught and fixed postincrement, aliased stack/source EAs, SR/CCR privilege and flag preservation, MOVEM base-in-list/order, PC-relative extension position, full-format PC indexing, ASL width-count overflow, and long DIV remainder/overflow.
- Capstone 5.0.9 has two relevant detail limitations: full-format PC-relative EA may be labelled AREGI_INDEX with `base_reg=PC` (never A16); 32/32 long DIV hides the distinct remainder register. Lowering handles these from the PC register identifier and raw extension word respectively.
- MAME parity, not undocumented hardware guesses: MAME and Musashi preserve the original base register value in MOVEM predecrement transfers, including its low-word-first long writes. Word DIV overflow differs in unpatched upstream Musashi: current MAME clears C before division while retaining undefined N/Z. Runtime peer owns the corresponding four-template reference-core patch. Arithmetic traps use 68020 format-2 frames, with next PC and instruction PC distinct.
- Integration acceptance is stricter than standalone milestones: root `integration` merges both branches, and only generated-C `landmakr` with no main-CPU fallback, attract, coin/start/controls, sound, and observed-output parity qualifies as DONE. The runtime capture script supersedes the initial compiler capture script because it retains taps and survives ROM-requested soft reset without duplicate callbacks.
- Actual-ROM lockstep first diverged at instruction 6,678,642, PC `0x4444`: Capstone reported full-format word base displacement `0xfa26` unsigned. Raw extension decoding now sign-extends base/outer words, handles MOVE's two EA extensions, and recognizes Capstone's zero-displacement brief-format misclassification. Regression cases cover these separately.
- Native bitfields (all eight operations), CMP2/CHK2, MOVEC, and RTE format 0/1/2 now lower without interpreter calls. The 5,000-case differential run passed all 5,000 with no unsupported cases, including 768 dynamic bitfield boundary cases. Bus-fault/coprocessor RTE formats remain outside the runtime's exception model; they raise format error as the reference Musashi does.
- After the runtime's stale-context watchdog reset fix, 50,000,000 actual-ROM instruction boundaries matched D/A/PC/SR and periodic RAM/device-buffer state through frame 1545. This semantic test synchronizes native time to reference time; it does not prove native timing or video/audio parity. Discovery still missed 1,265,436 executed instructions in that run, serviced by the diagnostic fallback; this is not native-only acceptance.
- Evidence priority correction: Land Maker ROM behavior plus its observed MAME output first; primary die/datasheet evidence next; WIP Taito F3 notes next; MAME source last. Neither notes nor MAME source is hardware ground truth. Runtime owns FDP source comparisons; conflicting choices must be recorded and switchable. Clean MAME baseline is the observable comparison target, not a claim of physical fidelity.
