FAUST 2.88.0 (https://faust.grame.fr): no FAUST library or architecture file is vendored. The FAUST compiler
(LGPL-2.1 or later) is build-time only: crates/f3rt-audio/faust/regen.sh runs it (-lang rust -double) to write the
checked-in crates/f3rt-audio/src/hle/faust/generated/*.rs. It is not linked into or shipped with f3rt. The generated
files contain the compiler's output for our .dsp sources and our architecture.rs. The DSP sources import no FAUST
standard library; the only import is the in-repo crates/f3rt-audio/faust/es5510.lib. The registry of named controls
(crates/f3rt-audio/src/hle/faust/support.rs) is project code, not derived from FAUST.
