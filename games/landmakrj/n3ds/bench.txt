# Land Maker 3DS bench timeline (F3_N3DS_BENCH). Install as sdmc:/3ds/f3-recomp/landmakrj/bench.txt.
# Format: runtime/debug/input_script.hpp (`FRAME scenario NAME` labels a section). Frames are
# Machine::frame + 1; the 3DS starts at frame 479 (fast boot ends after 478 frames).
#
# The same script plays on the desktop, which is how the timeline was explored:
#   cp <sdmc>/3ds/f3-recomp/landmakrj/eeprom/landmakrj-init.bin /tmp/e.bin
#   build/landmakrj/landmakrj --rom-dir roms/landmakrj --headless --no-audio --fast-boot off \
#     --eeprom /tmp/e.bin --renderer accurate --frames 18600 --dump-dir /tmp/d \
#     --dump-start 479 --dump-every 100 --inputs games/landmakrj/n3ds/bench.txt
# (--dump-dir writes rendered.bmp per dumped frame; --fast-boot off with the init EEPROM runs the
# exact frames of the 3DS fast boot. A landmakrj desktop build refuses `poke` rules because its
# game netplay hook is active: lift that check locally to explore.)
#
# Timeline (frames; 5 s perf windows, a scenario needs >= 12 whole windows = 3540 frames; each
# lasts >= 4300 frames = 73 s):
#   479-4778    attract: licence notice, Taito logo, intro movie, title, demo play
#   4779-9439   main menu: GAME SELECT (attract coin + start, tutorial skipped)
#   9440-13929  character select: PLAYER SELECT (b1 on the highlighted 1P BATTLE)
#   13930-18579 gameplay: map, VS, READY/GO, then 1P vs CPU with seeded random mashing
#   18580       end of the run
#
# The select screens count a timer down (a word at 0x407908, one per frame from 1200, digits are
# 120-frame steps) and leave when it expires, so each hold pokes it back to 1000 every frame.
# Mashing (seed=1 period=10) was picked from a sweep of seeds: it neither loses nor wins a round
# for over 6600 frames, with boss and dense sprite moments.
